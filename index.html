Space Mission Tools

Sixteen practical calculators a mission planner or astronaut actually uses — all running locally in your browser, no server round-trip required.

📡 Light-Speed Comm Delay

Pick source and destination — get one-way light time. Critical for Mars transit (~4–24 min) and deep-space probes.

⚖️ Weight on Other Worlds

Enter your Earth weight — see your weight on every planet and the Moon. Powered by each body's surface gravity.

🛰️ Orbital Velocity & Period

Pick a body and orbital altitude — get circular orbital velocity and one-orbit period. Uses v = √(GM/r).

⏱️ Mission Elapsed Time

Set your mission start — get a live T+ counter, just like NASA mission control. Counts up forever in your browser.

🚀 Delta-V Budget Estimator

Estimate the total Δv for common mission maneuvers. Real mission planning numbers, sourced from NASA reference tables.

—

☢️ Radiation Dose Estimator

Estimate cumulative radiation dose for a mission duration. ISS ~0.5 mSv/day; deep-space transit much higher.

—

🛸 Hohmann Transfer Orbit

Most fuel-efficient transfer between two circular orbits. Calculates transfer time and required Δv.

—

🏃 Escape Velocity

Minimum speed needed to break free from a body's gravitational pull — v = √(2GM/r).

—

📐 Cosmic Distance Converter

Convert between km, AU, light-years, and parsecs — the units astronomers actually use.

📡 Synchronous Orbit Altitude

Altitude needed for a satellite to match the body's rotational period (geostationary for Earth).

—

🚀 Tsiolkovsky Rocket Equation

The fundamental equation of rocketry: Δv = Isp·g·ln(m₀/m₁). Computes achievable Δv from mass ratio.

—

🌍 Habitable Zone Calculator

Find the "Goldilocks zone" around any star — where liquid water can exist on a planet's surface.

—

☀️ Solar Panel Power on Other Worlds

How much power a 1 m² solar panel generates on each body. Based on solar flux at that distance.

POWER PER 1 m² PANEL ON EACH BODY (W)

🕳️ Schwarzschild Radius (Black Hole)

The radius below which any mass becomes a black hole. rₛ = 2GM/c².

—

⏳ Relativistic Time Dilation

How much time slows for a fast-moving traveler (special relativity). At 99% of light speed, time runs 7× slower.

—

🌌 Cosmic Velocities (1st/2nd/3rd)

Three fundamental speeds: 1st = orbit, 2nd = escape, 3rd = leave the solar system from a body's orbit.

About this build

One file. Frontend only. Built for the NASA Space Apps Challenge.

AstroNova Cosmic Explorer is a single index.html file — HTML, CSS, and JavaScript all inline. There is no backend, no install step, no API key, and no build tool. You can double-click the file and it runs in any modern browser.

What's inside: an interactive solar system with 11 bodies (the Sun, all 8 planets, the Moon, and Pluto) — each in HD with a click-to-open datasheet. A star catalog of 8 notable discovered stars. Sixteen live mission tools that actually compute useful numbers for spaceflight: light-speed communication delay, weight on other worlds, orbital velocity & period, mission elapsed time, Δv budget estimation, and radiation dose estimation.

NASA Live Data section: Real, live data pulled directly from NASA's open APIs — the Astronomy Picture of the Day (APOD), the Mars rover photo archive (Curiosity / Perseverance / Opportunity / Spirit), the NASA Image & Video Library search, and today's Near-Earth Object tracker (NeoWs / CNEOS). No signup is required — NASA's public DEMO_KEY is used. All data is © NASA / public domain and used under NASA's Open Data terms of service. The full list of NASA resources used is documented inside the NASA Live Data section above, satisfying NASA Space Apps Challenge global-award eligibility.

Built for: NASA Space Apps Challenge, Artemis Lunar Base & Mars transit mission context. Drop the file on any static host (GitHub Pages, Netlify drop, Vercel) — or just open it locally. That's it.
